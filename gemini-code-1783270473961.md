# Formula1-AI: Training Pipeline & Evaluation

## 1. Automated Training Pipeline
The system utilizes an automated, modular training pipeline executed via `src/pipelines/train.py`. The pipeline enforces strict data leakage prevention through time-aware splitting.

### Pipeline Stages
1.  **Temporal Split:** Data is strictly split chronologically. Future races are never used to train models predicting past races.
2.  **Preprocessing:**
    * **Scaling:** Standard/MinMax scaling for continuous variables (e.g., track temperature, humidity).
    * **Encoding:** Target encoding and One-Hot Encoding for categorical variables (e.g., driver ID, constructor ID, circuit ID).
3.  **Training:** Fit baseline models -> Fit booster models -> Fit ensembles.
4.  **Cross-Validation:** Implement Time-Series Split (Walk-Forward Validation).
5.  **Tracking:** All runs, parameters, and artifacts are logged directly to MLflow.

## 2. Hyperparameter Tuning (Optuna)
Every primary model undergoes rigorous hyperparameter optimization using Optuna.
* **Minimum Trials:** 100 trials per model.
* **Search Space:**
    * `max_depth`: [3, 12]
    * `learning_rate`: [0.001, 0.1]
    * `n_estimators` (Trees): [100, 2000]
    * `num_leaves`: [20, 150]
    * `subsample` / `feature_fraction`: [0.5, 1.0]
    * `min_child_weight`: [1, 10]
    * `reg_alpha` / `reg_lambda` (Regularization): [1e-8, 10.0]
* **Early Stopping:** Implemented to prevent overfitting during booster training.

## 3. Model Metrics & Evaluation
Models are ranked and evaluated across a comprehensive suite of metrics stored in MLflow.

### Classification Metrics
* Accuracy, Precision, Recall, F1-Score
* ROC AUC & PR AUC (Crucial for imbalanced targets like DNF or Safety Car)
* Log Loss
* Calibration Curves (Reliability diagrams)
* Confusion Matrix

### Regression Metrics
* MAE (Mean Absolute Error)
* RMSE (Root Mean Squared Error)
* MAPE (Mean Absolute Percentage Error)
* R² (Coefficient of Determination)
* Residual Analysis

### Diagnostic Plots
* Learning Curves
* Validation Curves
