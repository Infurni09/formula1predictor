# Formula1-AI: Data Engineering & DuckDB Schema

## 1. Data Sources & Ingestion
The system automatically pulls, caches, and normalizes data from the following sources:
*   **FastF1:** Telemetry, lap timing, tire compounds, track temperature.
*   **Ergast API / OpenF1:** Historical race results, driver standings, constructor standings, circuit info.
*   **External APIs:** Historical weather data, track altitude/characteristics.

All downloads are cached locally in `data/raw/` using `.parquet` or SQLite to minimize API rate-limiting issues.

## 2. DuckDB Schema
A highly optimized, normalized relational schema implemented in DuckDB. 

### Core Tables
*   `drivers`: driver_id, name, dob, nationality, active_status.
*   `constructors`: constructor_id, name, nationality, active_status.
*   `circuits`: circuit_id, name, location, country, lat, long, altitude, track_type (street/permanent).
*   `races`: race_id, year, round, circuit_id, date, url, fp1_date, quali_date, sprint_date.

### Event Tables
*   `laps`: race_id, driver_id, lap_number, position, lap_time_ms, pit_stop, sector_1_ms, sector_2_ms, sector_3_ms, tyre_compound, tyre_age.
*   `pit_stops`: race_id, driver_id, stop_number, lap, duration_ms.
*   `qualifying`: race_id, driver_id, constructor_id, q1_ms, q2_ms, q3_ms, final_position.
*   `sprint`: race_id, driver_id, constructor_id, laps, grid, points.
*   `telemetry`: race_id, driver_id, lap_number, timestamp, speed, throttle, brake, rpm, gear, drs.
*   `weather`: race_id, timestamp, air_temp, track_temp, humidity, wind_speed, rainfall.

### Championship Tables
*   `championship_standings`: year, race_id, driver_id, constructor_id, points, position, wins.
*   `results`: race_id, driver_id, constructor_id, grid, finish_position, points, laps_completed, status (DNF reason).

## 3. ETL Pipeline Flow
1.  **Extract:** Async API calls -> Save to `data/raw/`.
2.  **Validate:** Pydantic schema validation on raw data.
3.  **Normalize:** Flatten nested JSONs, map ID cross-references between Ergast and FastF1.
4.  **Clean:** Handle missing telemetry, interpolate dropped weather packets.
5.  **Transform:** Convert all timestamps to standard UTC, lap times to milliseconds.
6.  **Feature Engineering:** Generate rolling averages, Elo ratings (see Features spec).
7.  **Store:** Load transformed data into DuckDB.
