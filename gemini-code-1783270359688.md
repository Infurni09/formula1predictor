# Formula1-AI: Project Architecture & Environment

## 1. Project Overview
Formula1-AI is a production-grade, end-to-end machine learning and analytics platform designed to mirror the software used by a Formula One team's strategy department. It integrates time-series forecasting, explainable AI, Monte Carlo simulations, and telemetry visualization.

## 2. Directory Structure
The repository strictly separates configuration, raw data, ETL pipelines, machine learning models, and visualization dashboards. No duplicate logic exists in notebooks.

Formula1-AI/
├── .github/                  # CI/CD workflows (GitHub Actions)
├── data/
│   ├── raw/                  # Immutable raw API dumps (JSON, CSV, Parquet)
│   ├── processed/            # Cleaned intermediate data
│   └── external/             # Third-party datasets (Weather, Track profiles)
├── docs/                     # Sphinx/MkDocs documentation
├── models/
│   ├── trained/              # Serialized models (.pkl, .onnx)
│   ├── checkpoints/          # Training checkpoints
│   └── artifacts/            # SHAP values, Optuna studies, MLflow logs
├── notebooks/                # Exploratory Data Analysis (strictly no core logic)
├── src/                      # Core application logic (Python 3.12+)
│   ├── api/                  # FastAPI endpoints
│   ├── config/               # Pydantic settings & YAML parsers
│   ├── database/             # DuckDB schema, migrations, ORM
│   ├── datasets/             # FastF1, Ergast, OpenF1 ingestion scripts
│   ├── etl/                  # Extract, Transform, Load pipelines
│   ├── features/             # Feature engineering functions
│   ├── models/               # Model definitions (XGBoost, LightGBM, etc.)
│   ├── training/             # Training loops, Optuna tuning, MLflow
│   ├── evaluation/           # Metrics, validation curves, backtesting
│   ├── prediction/           # Inference pipelines
│   ├── simulation/           # Monte Carlo race & season simulators
│   ├── visualization/        # Matplotlib/Plotly plotting utilities
│   ├── telemetry/            # FastF1 telemetry processors
│   ├── analytics/            # Strategy and historical analysis
│   ├── dashboard/            # Dash/Plotly frontend components
│   ├── utils/                # Logging, type checking, generic helpers
│   └── pipelines/            # Airflow/Prefect DAGs or main execution scripts
├── tests/                    # Pytest suite (unit, integration, e2e)
├── config/                   # YAML configuration files (models.yaml, etl.yaml)
├── dashboards/               # Standalone dashboard entry points
├── scripts/                  # Shell scripts (setup, docker run, db init)
├── README.md
├── LICENSE
├── requirements.txt
├── environment.yml
├── Dockerfile
└── docker-compose.yml

## 3. Environment & Coding Standards
*   **Language:** Python 3.12
*   **Typing:** Strict Type Hints (`typing` module, validated by `mypy`).
*   **Formatting:** Black (line length 88).
*   **Linting:** Ruff.
*   **Docstrings:** Google Style.
*   **Configuration:** YAML-driven configuration parsed via `pydantic`. No hardcoded magic numbers.
