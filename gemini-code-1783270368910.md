# Formula1-AI: Feature Engineering & ML Targets

## 1. Engineered Features
Advanced motorsport features computed during the ETL pipeline. Calculated using Polars/DuckDB for performance.

### Driver & Constructor Form
*   **Rolling Average Finish:** Last 3, 5, and 10 races.
*   **Dynamic Elo Rating:** Updates post-race based on teammates beaten and expected finish.
*   **Constructor Momentum:** Combined Elo of both drivers + recent point accumulation.
*   **Pole/Podium Conversion Rate:** Historical probability of staying in the top 3 when starting there.

### Pace & Strategy
*   **Average Gain from Qualifying:** `Finish Position - Grid Position` (Rolling average).
*   **Lap Consistency:** Standard deviation of non-pit lap times.
*   **Average Pit Stop Duration:** Constructor's median pit stop time over the last 5 races.
*   **Tyre Degradation Score:** Slope of lap times on a single compound (adjusted for fuel burn).
*   **Historical Pace:** Fastest lap comparison vs field median.

### Track & Environment Context
*   **Track Type Performance:** Driver's historical average finish on Street vs. Permanent circuits.
*   **Wet Weather Performance:** Elo rating adjusted specifically for races with `rainfall > 0`.
*   **Historical Weather Similarity:** KNN matching of current weekend weather to past races.

## 2. Machine Learning Targets
The system trains distinct models for the following targets:

| Target | Description | Type | Output / Metric |
| :--- | :--- | :--- | :--- |
| **1. Race Winner** | Probability of P1 finish. | Classification | Probability [0-1], Log Loss |
| **2. Podium** | Probability of P1-P3 finish. | Classification | Probability [0-1], ROC AUC |
| **3. DNF** | Probability of Not Finishing. | Binary Class | Binary (1/0), PR AUC |
| **4. Quali Position** | Expected grid position. | Regression | Float [1-20], MAE |
| **5. Finish Position** | Expected race result. | Regression | Float [1-20], RMSE |
| **6. Lap Time** | Predicted time for next lap. | Regression | Milliseconds, MAPE |
| **7. Pit Stop Timing** | Predicted lap for first pit stop. | Regression | Lap Number, MAE |
| **8. Safety Car** | Probability of SC deployment. | Classification | Probability [0-1], F1-Score |
| **9. Fastest Lap** | Probability of securing fastest lap. | Classification | Probability [0-1], Log Loss |
| **10. Championship** | Monte Carlo season outcome. | Simulation | % Win Probability |

## 3. Modeling & Optimization
*   **Algorithms:** LightGBM, XGBoost, CatBoost as primary boosters. Random Forest and SVM as baselines. Stacking/Voting Regressors for final ensembles.
*   **Hyperparameter Tuning:** Optuna (minimum 100 trials per model). Searching across `max_depth`, `learning_rate`, `subsample`, and `reg_alpha/lambda`.
*   **Validation:** Walk-forward time-series cross-validation (never train on future races to predict past races).
