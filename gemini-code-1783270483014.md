# Formula1-AI: Explainable AI & Visual Design

## 1. Explainable AI (XAI)
Every prediction made by the system must be transparent. The `src/analytics/` module integrates SHAP (SHapley Additive exPlanations) to crack open black-box models.

### Required SHAP Visualizations
* **Summary Plots:** Global feature importance across the entire dataset.
* **Waterfall Plots:** Local explanations for a specific prediction (e.g., *Why did the model predict a 75% chance of a safety car on Lap 14?*).
* **Force Plots:** Real-time push/pull of features influencing a live prediction.
* **Dependence Plots:** Non-linear feature effects (e.g., lap time degradation vs. tire age).
* **Interaction Plots:** How two features combine to affect the target (e.g., Track Temp * Tyres).

## 2. Interactive Dashboards (Frontend)
The frontend is built using Dash, Plotly, and FastAPI, designed to look and feel like enterprise strategy software (Bloomberg Terminal meets Mercedes AMG F1 pit wall).

### Visual Design Specifications
* **Theme:** Dark mode by default. High contrast for telemetry lines.
* **Interactivity:** Fully responsive. Hover states for telemetry traces, zoomable track maps.
* **Live Updates:** Animated transitions for simulated lap data.

### Core Dashboard Views
1.  **Race Strategy Center:** Compares predicted tire degradation curves between rival drivers.
2.  **Telemetry Overlay:** Visualizes Speed, RPM, Throttle, and Brake traces side-by-side.
3.  **Championship Tracker:** Displays dynamic Elo ratings and Monte Carlo championship probabilities.
4.  **XAI Inspector:** Allows a user to click any prediction and instantly view the SHAP waterfall plot explaining it.
